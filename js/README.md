# JavaScript Interview Cheat Sheet

A quick-revision repository for frontend interviews. Start with `javascript-cheat-sheet.js`, then use the focused files when you want more examples.

## Files

- `javascript-cheat-sheet.js` — compact, all-in-one reference for fundamentals, scope, closures, `this`, prototypes, arrays, promises, async/await, event loop, DOM/browser basics, and common interview traps.
- `01-fundamentals.js` — types, coercion, equality, scope, hoisting, closures, `this`, prototypes, and functions.
- `02-array-methods.js` — `map`, `filter`, `reduce`, `find`, `some`, `every`, `sort`, `flatMap`, and common patterns.
- `03-promises-async-await.js` — promise chaining, `async`/`await`, parallelism, error handling, and concurrency.
- `04-event-loop.js` — synchronous code, microtasks, timers, and output prediction.
- `05-interview-snippets.js` — debounce, throttle, deep/shallow copy notes, frequency counts, deduplication, and practical patterns.
- `06-output-questions.js` — small output-prediction exercises with answers in comments.
- `REVISION-CHECKLIST.md` — quick checklist for interview day.

## How to use

1. Read `javascript-cheat-sheet.js` for a 10–15 minute overview.
2. Before interviews, revise the focused files that match the job description.
3. Run examples with Node.js: `node filename.js`.
4. Hide/cover the answers in `06-output-questions.js` and predict outputs before checking.

## Important

This repo is a revision aid, not a substitute for explaining concepts in your own words. Be ready to explain *why* the output occurs and when you would use each pattern.
