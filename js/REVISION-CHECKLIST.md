# Interview-Day JavaScript Revision Checklist

## Fundamentals
- [ ] `let` / `const` / `var`, scope, hoisting, temporal dead zone
- [ ] Primitive vs reference values; `typeof null`; `Array.isArray`
- [ ] `===` vs `==`, truthy/falsy, `||` vs `??`, optional chaining
- [ ] Function declaration vs expression vs arrow function
- [ ] Closures and practical uses
- [ ] `this`, arrow-function `this`, `call`, `apply`, `bind`
- [ ] Prototypes, classes, inheritance
- [ ] Shallow copy vs deep copy; mutation vs immutability

## Arrays
- [ ] `map`, `filter`, `reduce`, `find`, `findIndex`
- [ ] `some`, `every`, `includes`
- [ ] `slice` vs `splice`
- [ ] `sort((a, b) => a - b)` for numeric ascending sort
- [ ] Deduplication with `Set`; grouping and frequency counting

## Async JavaScript
- [ ] Promise states and `.then` / `.catch` / `.finally`
- [ ] `async` always returns a Promise
- [ ] `await` and `try/catch`
- [ ] Sequential vs concurrent work with `Promise.all`
- [ ] `all`, `allSettled`, `race`, `any`
- [ ] Event loop: synchronous code, microtasks, timers
- [ ] Handle errors, loading states, cancellation/stale requests where relevant

## Browser / frontend
- [ ] DOM events, bubbling, `preventDefault`, `stopPropagation`
- [ ] localStorage vs sessionStorage vs cookies
- [ ] Debounce vs throttle
- [ ] Explain every code example out loud in simple language

## React interview tie-ins
- [ ] State updates and re-renders
- [ ] `useEffect` dependency behavior and cleanup
- [ ] `useMemo` caches a value; `useCallback` caches a function reference
- [ ] Controlled inputs, list keys, lifting state, props vs state
- [ ] Loading/error/empty states for API-driven UI
